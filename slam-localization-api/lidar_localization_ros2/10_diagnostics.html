10. 診断・トラブル対処

Livox

ros2 topic hz /livox/lidar
ros2 topic hz /livox/imu
ros2 topic type /livox/lidar

Map

ros2 topic info /initial_map -v
ros2 topic echo /initial_map  --qos-durability transient_local  --qos-reliability reliable  --once --field width

TF

ros2 run tf2_ros tf2_echo world map
ros2 run tf2_ros tf2_echo map livox_frame

Localization

ros2 topic echo /alignment_status
ros2 topic hz /pcl_pose

IMU preintegration

imu_preintegration_status: imu_preintegration_prediction_active
registration_seed_source: imu_preintegration
