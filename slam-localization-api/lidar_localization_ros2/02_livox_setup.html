2. Livox MID-360 セットアップ

公式 Livox ROS Driver 2 は Ubuntu 22.04 / ROS 2 Humble をサポートしています。PointCloud2で使用するため rviz_MID360_launch.py 系を使います。

2.1 ネットワーク

公式のMID-360サンプル設定は LiDAR 192.168.1.12、PC側 192.168.1.5 です。 使用環境に合わせてNICとJSONを揃えます。

ip addr

# 例: 有線NICを 192.168.1.5/24 に設定
# NetworkManager GUIで設定してもよい

2.2 Livox-SDK2

sudo apt update
sudo apt install -y cmake git

cd ~/workspace
git clone https://github.com/Livox-SDK/Livox-SDK2.git
cd Livox-SDK2
mkdir -p build && cd build
cmake ..
make -j$(nproc)
sudo make install
sudo ldconfig

2.3 livox_ros_driver2

重要: 公式 build.sh humble はワークスペースの ../../build と ../../install を削除します。 他パッケージが入った ~/ros2_ws では実行せず、Livox専用ワークスペースを使う方が安全です。
mkdir -p ~/livox_ws/src
cd ~/livox_ws/src
git clone https://github.com/Livox-SDK/livox_ros_driver2.git

source /opt/ros/humble/setup.bash
cd ~/livox_ws/src/livox_ros_driver2
./build.sh humble

source ~/livox_ws/install/setup.bash

2.4 MID360_config.json

~/livox_ws/src/livox_ros_driver2/config/MID360_config.json

少なくともPC側IPとLiDAR IPを実ネットワークに合わせます。

"host_net_info": {
  "cmd_data_ip"   : "192.168.1.5",
  "point_data_ip" : "192.168.1.5",
  "imu_data_ip"   : "192.168.1.5"
},
"lidar_configs": [
  { "ip" : "192.168.1.12" }
]

2.5 起動

source /opt/ros/humble/setup.bash
source ~/livox_ws/install/setup.bash

ros2 launch livox_ros_driver2 rviz_MID360_launch.py

このlaunchは xfer_format=0 で PointCloud2をPublishし、frame_id=livox_frame が標準設定です。

2.6 確認

ros2 topic list | grep livox
ros2 topic type /livox/lidar
ros2 topic type /livox/imu
ros2 topic hz /livox/lidar
ros2 topic hz /livox/imu
ros2 topic echo /livox/lidar --once --field header

Localization用には /livox/lidar = sensor_msgs/msg/PointCloud2 が必須です。

2.7 【オプション】最短距離・同行者領域を除外する場合

この処理は任意です。 通常は生の /livox/lidar をそのまま利用できます。 地図への写り込みを抑える必要がある場合、同行者やセンサ保持者を消す設定は MID-360本体のJSONではなくROS2側のPointCloud2フィルタで行う。 Livox ROS Driver 2の公式READMEにある blind_spot_set は HAP LiDARのみの設定で、MID-360の設定例にはない。

scan_min_range はGLIMのmapping入力には効かない。 これはlidar_localization_ros2側の設定なので、 GLIM地図から人物を消したい場合に限り、GLIMへ入る前の /livox/lidar をフィルタする。基本手順と任意フィルタの使い分けは3章を参照する。
