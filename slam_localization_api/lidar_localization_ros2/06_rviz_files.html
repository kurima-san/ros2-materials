6. 専用Launch・RViz

5.1 ファイル配置

cp mid360_handheld_localization.launch.py   ~/ros2_ws/src/lidar_localization_ros2/launch/

cp mid360_handheld.yaml   ~/ros2_ws/src/lidar_localization_ros2/param/

cp mid360_handheld.rviz   ~/ros2_ws/src/lidar_localization_ros2/param/

cd ~/ros2_ws
colcon build --symlink-install --packages-select lidar_localization_ros2
source install/setup.bash

5.2 統合Launch

統合Launchは world → map static TF、localizer本体、RVizを同時に起動します。

5.3 RViz

項目設定
Fixed Framemap
Initial MapPointCloud2 /initial_map, Reliable, Transient Local
Livox ScanPointCloud2 /livox/lidar
Path/path
