7. リアルタイム運用

use_sim_time=false

Terminal 1: Livox

source /opt/ros/humble/setup.bash
source ~/livox_ws/install/setup.bash
ros2 launch livox_ros_driver2 rviz_MID360_launch.py

Terminal 2: Localization + RViz

source /opt/ros/humble/setup.bash
source ~/livox_ws/install/setup.bash
source ~/ros2_ws/install/setup.bash

ros2 launch lidar_localization_ros2   mid360_handheld_localization.launch.py   use_sim_time:=false

初期姿勢

RVizの 2D Pose Estimate でPCD上の現在位置・向きを指定してから歩き始めます。
