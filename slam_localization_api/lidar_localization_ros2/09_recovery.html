9. 途中失敗時の復旧

基本は 停止 → 新しい /initialpose → 状態確認 → 再開 です。

rosbag

  1. SPACE でPause
  2. RVizで現在地点を確認
  3. 2D Pose Estimateで位置・yawを再指定
  4. /alignment_status を確認
  5. SPACEでResume

Realtime

  1. 歩行/ロボット移動を停止
  2. MID-360を静止
  3. 2D Pose Estimateを再送
  4. message: ok が数scan安定してから移動再開
ros2 topic echo /alignment_status
ros2 topic echo /reinitialization_requested
