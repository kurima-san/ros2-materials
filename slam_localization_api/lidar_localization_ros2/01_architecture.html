1. 全体構成

Livox MID-360
  ├─ /livox/lidar : sensor_msgs/msg/PointCloud2
  │       ↓
  │  Mapping pre-filter
  │  (min range / self / companion CropBox)
  │       ↓
  │  /livox/lidar_mapping
  │
  └─ /livox/imu   : sensor_msgs/msg/Imu
          │
          ├──────────────→ GLIM → mapping dump → PLY/PCD
          │
          └──────────────→ lidar_localization_ros2
                                   │
                                   ├─ /pcl_pose
                                   ├─ /path
                                   ├─ /alignment_status
                                   └─ map → livox_frame

今回の手持ち構成ではロボットodometryを使用せず、base_frame_id=livox_frame、 enable_map_odom_tf=false として map → livox_frame を直接推定します。
